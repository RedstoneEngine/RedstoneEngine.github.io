WorldGenV1

The WorldGenV1 World Assets are currently only modifiable via Modding. Asset Pack modification is coming with Chapter 1 soon though! It's recommended to only do small modifications like ore spawns using WorldGenV1 while for creating full worlds it's recommended to use the more up to date WorldGenV2. In order to have an Instance use the WorldGenV1 generator, set the WorldGen: Type to "Hytale" with the specific World's Assets being defined at WorldGen: Name.

For the default World you spawn into, this value is set as "Default".
instance.bson
{ ... "WorldGen": { "Type": "Hytale", "Name": "Default" } ... } This section will be updated whenever Asset Pack modification becomes available!
