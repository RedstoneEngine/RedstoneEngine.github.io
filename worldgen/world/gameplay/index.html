Gameplay

While not needed for Generating a World, the World's Gameplay can be a very important aspect of curating an experience for the Players! Gameplay is defined by 2 Assets, the GameplayConfig and Instance. The Gameplay Config can be changed via Portal Fragments while the Instance/World gameplay properties can be modified via Commands. Both have their own properties as well as some overlap. Anything defined in the Instance will take priority!
Gameplay Config Files

File: Instance

Contains a list of Gameplay Configurations as well as a reference to a GameplayConfig Asset.

Asset: GameplayConfig

Contains a list of Gameplay Configurations.

Commands

/world settings ... - Change the Gameplay Settings in the World File

Asset: PortalType

Overrides the World with a different GameplayConfig Asset than defined in the Instance File.
Default is the Portal GameplayConfig Asset. The amount of Gameplay configurations you can change is too much to comprehesively go over here, so I encourage you to check the docs and the GameplayConfig Asset in the Asset Editor!
